# VersionRAG：可更新、可回滚、可追溯的中文知识库

基于 DomainRAG 历史中文资料建立检索评测底座，增加文档草稿、后台构建、双索引整版发布与回滚。问答固定使用一个知识版本，由 DeepSeek 生成带引用的答案。提供中文问答及资料管理页面。

复用 FlashRAG 采用的 BM25s 组件，参考其组件组织；本目录实现中文适配、模型 API 接入、断点索引、服务与评测。不是完整 FlashRAG Pipeline，不宣称原创检索/模型算法或自行完成网页采集、OCR。原始数据已经预处理，上游提交和许可见 [选型记录](PROJECT_DECISION.md)。

```powershell
.\启动.cmd
```

需要自行指定启动参数时使用原始命令：

```powershell
cd D:/interview/rag-domain-study
.venv/Scripts/python.exe -X utf8 -m uvicorn app.api:app --host 127.0.0.1 --port 8018
```

启动日志显示地址后访问，Ctrl+C 停止。选择检索方法后，“只看资料”不调用生成模型，“生成回答”调用 DeepSeek。服务只监听本机。

## 新环境复现

需要 Python 3.12。公开仓库保留代码、数据、所需原始任务文件与实验报告，排除密钥、虚拟环境、本机知识数据库和索引；首次使用需要配置自己的模型Key并构建索引。

```powershell
git clone https://github.com/89799969/VersionRAG.git
cd VersionRAG
```

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock.txt
Copy-Item .env.example .env
```

在本机 `.env` 填入 `DEEPSEEK_API_KEY` 和 `SILICONFLOW_API_KEY`，不要提交真实配置。DeepSeek 默认本次实测的 `deepseek-flash`，见[官方文档](https://api-docs.deepseek.com/)。

```powershell
.venv/Scripts/python.exe -X utf8 -m pytest -q
.venv/Scripts/python.exe -X utf8 scripts/run_baseline.py build
.venv/Scripts/python.exe -X utf8 scripts/build_dense.py --backend api
.venv/Scripts/python.exe -X utf8 -m scripts.seed_knowledge
.venv/Scripts/python.exe -X utf8 -m uvicorn app.api:app --host 127.0.0.1 --port 8018
```

默认硅基流动 `BAAI/bge-m3` 与 `BAAI/bge-reranker-v2-m3` 在 2026-10-04 核对的[官方价格页](https://siliconflow.cn/pricing)标为免费，不自动回退到 Pro 型号。首次构建发送语料到所选服务，本轮约 810 秒，无文档输入截断；实际耗时受网络和限速影响。每批保存进度，中断后重跑同一命令续接。后续问题只编码查询，文档向量从本机缓存读取。

`seed_knowledge`只在知识库为空且服务停止时执行，复制并验证已有索引，不重新请求文档向量化。没有导入知识版本时，问答回退到原固定资料，响应标为`baseline-static`。新增知识库保存在`artifacts/knowledge`，不进入源码交付包。

本地 ONNX 仅为可选后端，需额外依赖和下载模型；本次本地模型未下载成功，不作为主流程。

复现新增证据：已从交付包建立新的Python3.12环境，只安装默认锁定依赖，最终26项测试通过，全部BM25索引重建，页面/健康/检索接口通过；新环境没有torch/transformers/onnxruntime/tokenizers。没有在该新环境重复远端Dense编码和真实生成；原机完整链路另有验证。见`fresh_environment_check.json`。
